# Changelog

All notable changes to this project are documented here. The project follows
[Semantic Versioning](https://semver.org/) from the first public preview.

## [Unreleased]

- Add portable companion-skill installation once their public repositories are available.
- Add externally judged and second-host validation evidence.

## [0.1.1] - 2026-09-29

### Added

- A 60-second animated synthetic workflow demonstration and reproducible render script.
- A standalone dark-theme project site with a GitHub Pages deployment workflow.
- A tested skill-only installation path through the `skills.sh` CLI.
- A public 20-minute pilot, dedicated feedback issue form, and bilingual launch kit.
- A complete synthetic input-to-handoff case study and versioned release notes.
- A source-controlled public Plugins Directory submission packet with listing
  copy, starter prompts, five positive cases, and three negative cases.

### Changed

- Replace the former GitHub username in install paths, manifests, citation
  metadata, license notices, and verification links.
- Add a two-command installation path, bilingual 60-second product tour, and
  reproducible quick-start walkthrough.
- Add public release automation and clean-host validation.
- Clarify that the orchestration core is general while the deepest current
  specialization is econometrics, statistics, and quantitative economics.

## [0.1.0] - 2026-09-29

### Added

- Portable Agent Plugin manifest and Codex compatibility manifest.
- Repo-local plugin marketplace for local installation and testing.
- Public documentation, contribution, security, support, citation, and provenance files.
- Machine-readable companion-skill dependency inventory.
- Public-release validator and local/CI check runner.
- Linux and macOS CI definitions.
- Machine-readable controller inventory and CLI entrypoint smoke checks.
- Machine-readable CLI exit-code contracts with public command-specific guidance.
- Machine-readable state-schema inventory, migration policy, and release-time
  completeness checks.
- Distinct schema identifiers for input contracts and their derived reports.
- Python 3.9 support, verified by the complete local check suite.
- A synthetic quick-start project that contains no unpublished research material.
- An isolated, offline smoke test for the synthetic quick-start initialization path.
- A runnable offline-job example covering handle-bound waiting, dependent-work
  refusal, and terminal resumption.
- Release-workflow enforcement that uploads both the archive and its checksum.
- A deterministic in-archive `MANIFEST.sha256` covering every packaged source file.
- A cross-platform release verifier with package self-verification and tamper tests.
- Public-tag provenance attestation plus a checked inventory of CI-only Actions.

### Included workflow capabilities

- Evidence-bound stage handoffs and resumable project state.
- Candidate idea portfolios and search-frontier controls.
- Empirical-result contracts and release-handoff checks.
- Non-regression contracts for continuous revision.
- Handle-bound waits for offline simulations and other long-running jobs.
- Paired token/quality evaluation without claiming unmeasured savings.
- Public proof-lineage manifest/status schemas, typed dependency graph, and
  hash-bound read-only interoperability controller without theorem content.

### Evidence boundary

- Local workflow regression tests exist for the bundled controllers.
- This release does not claim exhaustive literature coverage, guaranteed novelty,
  theorem correctness, identification validity, or publication success.
- Independent external scoring, a second-host run, and a second-paper holdout are
  not part of the v0.1.0 evidence package.
