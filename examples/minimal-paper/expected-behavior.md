# Expected behavior

A conforming run should:

- classify the project provisionally and preserve the unresolved classification;
- generate materially different candidate mechanisms rather than title variants;
- identify named and de-anchored literature-search paths;
- mark nearest-neighbor and novelty judgments as pending until sources are read;
- propose a cheap analytical or numerical falsifier for each retained candidate;
- record rejection or parking reasons and evidence-based reopen conditions;
- avoid writing simulated numbers, proof claims, or contribution language;
- continue setup work that remains valid under all plausible future results;
- report missing companion capabilities without treating them as completed stages.

The run need not select a final idea. A well-evidenced rejection or a smaller
reviewable candidate is a valid outcome.
