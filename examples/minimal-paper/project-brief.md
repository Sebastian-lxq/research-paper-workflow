# Synthetic research brief

## Broad direction

Specification testing with a nuisance function estimated by a flexible learner.

## Motivation

Classical calibration may become unreliable when the nuisance estimate converges
slowly or changes the effective null distribution.

## Unknowns

- Which existing tests already cover the same estimand and learner interaction?
- Is the real gap a new statistic, a calibration result, or only an implementation detail?
- What is the weakest toy model that could falsify the proposed mechanism?
- Which conclusions would require a theorem, a simulation, or both?

## Constraints

- No external data is supplied.
- No literature search has yet been run.
- No theorem, proof, code, or simulation result exists.
- The task may create local planning state but must not fabricate scientific evidence.
