# Support

Use GitHub Discussions for usage questions and workflow design conversations.
Use GitHub Issues for reproducible bugs and scoped feature requests. Use the
private process in `SECURITY.md` for vulnerabilities or accidental exposure of
restricted research material.

Before requesting help, run:

```bash
python3 scripts/run_checks.py
```

Include the plugin version, operating system, Python version, the failing
command, and a minimal synthetic reproducer. Do not upload an unpublished paper,
private mentor corpus, raw confidential data, API key, or full project state.

The maintainers can help diagnose workflow and controller behavior. They cannot
certify a paper's novelty, theorem correctness, identification, or journal fit.
