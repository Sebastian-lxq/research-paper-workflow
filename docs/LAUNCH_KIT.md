## One-sentence description

Research Paper Workflow is an open-source, evidence-grounded Agent Plugin that
coordinates quantitative research from idea discovery through reproducible
delivery, with first-class support for econometrics and quantitative economics.

## Short English post

I have released Research Paper Workflow, an open-source Agent Plugin for
evidence-grounded quantitative research. It coordinates idea discovery,
literature, research design, proofs, empirical work, simulation, writing,
independent review, and revision without allowing downstream claims to move
beyond the evidence that exists.

The orchestration layer is general, while the deepest current routes and
interfaces focus on econometrics, statistics, and quantitative economics. The
repository includes a detailed capability map, a two-command Codex install, an
open `SKILL.md` installation path, deterministic release archives, and a public
pilot for early users.

Project: https://github.com/XuQingAcademic/research-paper-workflow

## LinkedIn-style post

Research projects rarely fail because one isolated task is impossible. More
often, the handoff fails: a literature gap disappears from the proof plan, a
pilot result becomes production evidence, or a long simulation blocks unrelated
work while result-dependent writing moves too early.

Research Paper Workflow makes those boundaries explicit. It maintains resumable
state, evidence gates, offline-job handles, proof-lineage interfaces, and
non-regression contracts across a quantitative paper. It is general at the
orchestration layer and currently specializes most deeply in econometrics,
statistics, and quantitative economics.

The project is an MIT-licensed Research Preview. It does not promise novelty,
theorem correctness, identification, publication, or exhaustive search. Instead,
it makes the missing evidence and next safe action inspectable.

The repository includes a detailed capability map and a 20-minute pilot path:
https://github.com/XuQingAcademic/research-paper-workflow

Feedback from researchers and research-tool builders is welcome.

## Community post

**Title:** Open-source, evidence-gated workflow for econometrics and quantitative research

I am looking for feedback on Research Paper Workflow, an MIT-licensed Research
Preview for coordinating multi-stage quantitative papers. The project focuses on
the transitions between idea discovery, literature, design, theory, empirical
evidence, simulation, writing, review, and revision.

The intended behavior is conservative: unresolved literature remains pending,
simulation-dependent prose waits, missing specialist capabilities stay visible,
and a structurally valid record is not presented as scientific validation. The
current reference domain is econometrics, but the orchestration and state layer
is designed to be extensible.

The repository includes a synthetic example and a claim-by-claim capability
map, so the core behavior can be inspected without private research material.
I would especially value reports about installation friction, incorrect routing,
state/resume behavior, and places where the evidence boundary is unclear.

Repository: https://github.com/XuQingAcademic/research-paper-workflow

## Pilot invitation

I am recruiting 5–10 early users in econometrics, statistics, quantitative
economics, and adjacent quantitative fields. The pilot takes about 20 minutes:
install the workflow, run the synthetic example, try one public or synthetic
research brief, resume once, and report the first confusing or incorrect
behavior. No unpublished material is required.

Pilot guide:
